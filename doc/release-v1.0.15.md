# v1.0.15 研发进度清理修正

- “清空计划”同时清除当前国家、军种的载具研发进度，无需逐辆清除。
- 配件窗口的“清除已研发”同时清除当前载具的配件进度；“清空目标”仅取消目标，保留进度。
- 清理结果保存到当前浏览器，刷新后不会恢复；其他科技树的记录不受影响。
- 同步中英文介绍和七种语言的更新日志。

## 下载与使用

Windows 用户下载 `WarThunderResearchCalculator-v1.0.15-portable.zip`，解压到新文件夹后运行 `WarThunderResearchCalculator.exe`。启动前请退出旧版，无需另外安装 Node.js。不带 `portable` 的 ZIP 为源码包。

本次不修改游戏费用、数据快照或规划规则。发布账号仍为 Plastic-time。
