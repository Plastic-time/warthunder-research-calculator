# v1.0.21 选中状态与操作区优化

## 更清楚的选中状态

- 目标载具使用更醒目的金色轮廓、加粗侧条和带勾的实心“目标”标签。
- 自动规划加入的路线提高边框和背景对比度。已拥有、途经点和等级补足仍保留各自的状态颜色。
- 折叠载具窗口同步目标样式。主科技树卡片尺寸、配件入口和 Wiki 按钮位置保持不变。

## 更整齐的操作区

- 搜索和下拉控件在桌面端统一为 40px，手机端为 48px，统一文字基线、间距和短促反馈。
- 中等宽度下，批量选择区域自动换行，避免筛选栏被挤出横向滚动。
- 手机筛选面板区分字段与批量操作；全选仍在自动补位选项右侧。
- 改善多语言下拉选项显示，避免长文字截断；保留全选、取消及键盘焦点提示。

本次只调整界面，不修改计算逻辑、载具价格或配件数据。游戏版本仍显示 2.59.0.38，既有数据修正范围不变。

## 下载

Windows 用户下载 `WarThunderResearchCalculator-v1.0.21-portable.zip`。退出旧版，解压后运行 `WarThunderResearchCalculator.exe`，无需另装 Node.js。不带 `portable` 的 ZIP 为源码包。

## English

- Target vehicles now have a clear gold outline, a stronger side stripe, and a checked target label. Folder cards use the same style.
- Automatically added routes are easier to see. Owned vehicles, waypoints, and rank fillers retain their distinct colors.
- Search and dropdown controls use consistent heights: 40px on desktop and 48px on mobile.
- The toolbar wraps at medium widths. Mobile filters separate fields from bulk actions.
- Longer translations fit without clipping. Select all, deselect, and keyboard focus indicators still work.

Card sizes, calculations, vehicle prices, and modification data are unchanged.
