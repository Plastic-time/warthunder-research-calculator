# v1.0.18 F4U-7 配件数据更新

- 按游戏配置 2.59.0.38 更新法国 F4U-7，共 12 项配件费用发生变化。
- 20 毫米机炮翻新由第三层移至第二层，费用为 1,800 RP / 3,300 SL。
- 第二层解锁下一层所需数量由 2 改为 3；第三层由 4 改为 3。
- 全配件合计由 47,400 RP / 86,200 SL 改为 47,800 RP / 86,900 SL。
- 保留真实研发前置，不把新增的排版关系当成前置。空战优先和已填写进度继续生效。
- 页面显示游戏版本 2.59.0.38；本次为局部修正，不代表整套数据已升级。其他载具、此前人工确认修正和规划算法不变。

来源：[固定提交 359efba49](https://github.com/gszabi99/War-Thunder-Datamine/blob/359efba49b035374b225ee6327e889b2a46aaa6b/char.vromfs.bin_u/config/wpcost.blkx)。完整基础快照仍为 2.59.0.17；CA-27 的 2.59.0.34 局部修正保留。
