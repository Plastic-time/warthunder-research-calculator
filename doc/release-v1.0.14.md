# v1.0.14 研发进度与手机操作更新

- 新增载具研发进度：右键或手机长按载具，选择“研发进度”，填写已投入 RP。预算、自动规划和路线导出按剩余 RP 计算。
- 配件窗口新增“选择目标 / 研发进度”切换，支持逐项记录已投入 RP，并按剩余费用选择等级补足配件。
- 进度保存在当前浏览器，刷新后保留；填 0 可清除。银狮费用不变，填满 RP 不会自动标记已拥有或已研发。
- 手机长按菜单的进度入口保持至少 44px 触摸高度。隐藏菜单项不再触发按压动画；补充“更多”菜单、使用指南、按钮回弹和长按滑动的测试。
- Windows 版同步此前的网页更新：按等级批量标记本级及以下普通载具、确认列表、撤销，以及独立更新日志。等级 I 的提示仅显示本级。
- 更新中英文 README，补充进度和手机操作说明。

## 下载与使用

下载 `WarThunderResearchCalculator-v1.0.14-portable.zip`，解压到新文件夹，运行 `WarThunderResearchCalculator.exe`。启动前请退出旧版；无需另外安装 Node.js。不带 `portable` 的 ZIP 为源码包。

计划和进度不跨浏览器或设备同步。清除浏览器站点数据会删除记录。

本次不更新游戏数据快照，保留已有费用及已确认修正。发布账号仍为 Plastic-time。
