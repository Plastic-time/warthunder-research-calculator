# v1.0.26 科技树规划状态优化

## 更新内容

- 主科技树卡片上沿统一显示图标与状态签：金色目标、蓝色必经、紫色补足、绿色已拥有。途经点保留独立标记。
- 补足载具使用虚线边框，目标保留更醒目的实线边框，不仅依靠颜色区分。
- 状态签不占用内容行，不扩大卡片，也不遮挡 Wiki 和配件按钮。取消状态后恢复原有外观。
- 七种界面语言同步；截图导出保留状态标记。
- 仅调整主科技树显示。配件窗口、规划算法、RP/SL 数据和保存的研发进度不变。游戏版本说明仍为 2.59.0.50。

## 下载

Windows 下载 `WarThunderResearchCalculator-v1.0.26-portable.zip`，解压后运行 `WarThunderResearchCalculator.exe`，无需另装 Node.js。

## English

- Tech-tree cards now show distinct icons and labels for targets, required vehicles, rank fillers and owned vehicles. Waypoints keep a separate marker.
- Rank fillers have dashed borders. Targets retain stronger solid borders.
- Labels do not enlarge cards or cover the Wiki and modification buttons. Clearing a state restores the normal appearance.
- All seven interface languages are supported. Exported tree images retain the markers.
- This is a main-tree visual update. Modification dialogs, planning rules, RP/SL data and saved research progress are unchanged. The displayed game version remains 2.59.0.50.

Browser checks cover desktop and simulated mobile sizes. Physical phones and Safari have not been verified.
