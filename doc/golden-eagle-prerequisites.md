Source: `char.vromfs.bin_u/config/wpcost.blkx`, game version 2.59.0.17,
Datamine revision `510a793c2bdb01c51475118199c7b66b72935ff1`.
The fixture records the tier, reqModification and prevModification fields for
every visible modification on `f_15c_golden_eagle`.

Only reqModification represents a research prerequisite. prevModification is
layout ordering, as already verified for the Rafale correction.

- Compressor -> boosters -> wings repair -> engine.
- Basic countermeasures -> BOL -> G-suit -> EFS.
- Cannon upgrade -> GBU-39.
- JDAM -> GBU-8 -> GBU-53.

Five genuine edges remain:

- M60 belts -> new cannon.
- AIM-9M -> AIM-120C -> AIM-120D.
- SNIPER -> LGBU -> APKWS.

RP, SL, GE, membership, tiers, tier unlock counts, imagery, names and grid
positions are unchanged. In this configuration boosters are tier II and the
G-suit is tier III. Planning preferences do not move them between tiers.

Other aircraft are not regenerated by this correction. Existing user-confirmed
price corrections remain untouched.
